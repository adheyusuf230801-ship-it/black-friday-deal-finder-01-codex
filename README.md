DealHound Black Friday is a static deal finder holding 22 Black Friday deals checked on 27 Nov 2026: each deal shows its product, store, store link, sale and usual prices, discount, verdict badge, source and check time, with search and filters by category, store and discount. Node 22 stdlib only.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
